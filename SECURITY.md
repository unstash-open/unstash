# Security

Please avoid posting an exploitable vulnerability publicly before it is fixed.
Use the repository's private security-advisory form for vulnerability details:
https://github.com/unstash-open/unstash/security/advisories/new. For a public,
non-sensitive question, open an issue without exploit details or private data.

The default disclosure target is an acknowledgement within two business days,
an initial triage decision within five business days and coordinated status
updates until remediation. These are response targets, not a bounty promise.

The project never needs a wallet seed phrase or private key. The campaign site
uses only the public receiving address. Anyone asking for a seed phrase,
signature or “wallet verification” on behalf of Unstash is not part of this
project.
