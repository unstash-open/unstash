## Next Reddit update

**Title**

I shipped a Reddit saved-post importer that asks for no account access

**Body**

The first Unstash prototype required pasting saved links one at a time. The new
build imports Reddit's official `saved_posts.csv` and `saved_comments.csv`
files directly in the browser.

It asks for no Reddit login or OAuth token. The file never leaves the device,
duplicate permalinks are skipped, and every imported item gets a Read / Make /
Keep action before it enters the local queue.

What works now:

- local import of Reddit's saved-post and saved-comment CSV files;
- manual link capture;
- action labels, search, completion and Markdown export;
- no account, tracking or remote database.

Prototype: https://unstash-open.vercel.app/prototype

Source: https://github.com/unstash-open/unstash
