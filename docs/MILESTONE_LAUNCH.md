## Next Reddit update

**Title**

I am designing one-click Reddit import without broad account access — what
would you reject?

**Body**

The first Unstash prototype helped me test the basic loop: paste a saved link,
choose Read / Make / Keep, finish items and export everything to Markdown. It
runs locally in the browser with no account.

The most repeated missing piece is obvious: manually pasting saved Reddit posts
is friction. I am now designing the import so it asks for the smallest useful
permission set, shows exactly what is read, and keeps imported links on-device.

Before I lock the flow, I would value criticism of three choices:

1. one-time import or optional periodic sync;
2. explicit preview before anything enters the queue;
3. local-only storage with Markdown export as the escape hatch.

Prototype: https://unstash-open.vercel.app/prototype

Source: https://github.com/unstash-open/unstash

contribution is required to test or criticize the product.

Which permission or sync behavior would make you reject this immediately?
